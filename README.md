# TaskTracker

## About

TaskTracker is a simple Java program that helps users manage and track tasks.

## Features

- Add new tasks
- View existing tasks
- Track task status
- Assign a due date to each task
- Assign a priority to each task

## Methods

| Method | Description |
| --- | --- |
| main | Starts the program |
| showTitle | Displays the task list title |
| showTask | Displays a task |

## How to Run

```bash
javac Main.java
java Main
```
